# 笔记本 MCP 部署与游戏启动记录

最后更新：2026-07-28

## 已实现能力

- 小智通过群晖桥接器访问 Windows 笔记本 MCP 代理，可查询笔记本状态、打开白名单应用和按需拍摄摄像头照片。
- Windows 登录后自动启动任务 `Xiaozhi Laptop MCP Agent` 会在普通用户、交互式会话中后台启动代理；监听笔记本 Tailscale 地址的 TCP `8765`，MCP 地址为 `/mcp`。
- 普通白名单应用仍以普通 Windows 用户权限直接启动。
- 以下游戏使用固定、预先创建的 Windows 高权限任务启动：
  - `Xiaozhi Game - WeGame`
  - `Xiaozhi Game - VALORANT`
  - `Xiaozhi Game - League of Legends`

## 故障与处理

### 笔记本工具从小智 MCP 页面消失

排查确认群晖桥接器已读取 `PC_MCP_URL` 并在运行时配置中包含 `windows-laptop`；故障原因是笔记本代理未运行、TCP `8765` 没有监听，导致群晖无法连通笔记本 Tailscale 地址。

已恢复代理源码和启动脚本，并验证该端口重新监听。群晖桥接器连接恢复后，笔记本工具会与 Home Assistant、提醒工具同时出现在同一个小智 MCP 接入点中。

### 游戏语音启动被回答为“需要管理员权限”

历史审计记录显示普通应用曾成功调用，但没有游戏工具调用记录；因此其中一部分“需要管理员权限”是模型未调用工具时的口头判断。另一些游戏启动器或反作弊/更新流程确实可能需要 Windows 提权。

处理方式不是授予小智任意管理员能力，而是仅创建三个固定可执行文件的 Windows 高权限任务。笔记本 MCP 只可调用这些已命名任务，不能传入命令行、路径或任意任务名。

## 安全边界

- 游戏任务只在 Windows 用户已登录的交互式会话中可见和可用；电脑关机或未登录时无法远程启动游戏。
- 小智不具备 Windows 管理员 Shell、任意命令执行、任意路径启动或自动确认 UAC 的能力。
- 首次创建/更新固定高权限任务时需要用户在 Windows UAC 中明确确认；日常语音启动固定游戏不再需要重复确认。
- `apps.json` 为本机私有应用白名单，包含本机路径，不提交到 Git；摄像头照片、动作日志和代理运行日志同样不提交。

## 后续维护

- 若游戏安装位置改变，先更新本机 `apps.json`，再以管理员身份重新执行固定游戏任务配置脚本。
- 若笔记本重启后工具不可用，先确认已登录 Windows、Tailscale 已连接，以及 `Xiaozhi Laptop MCP Agent` 自动启动任务已运行。
- 当前 `deploy/windows-mcp-agent` 为本机部署目录；后续需要纳入正式版本控制时，应在笔记本 MCP 功能分支上只提交源码、示例配置和文档，绝不提交 `apps.json`、照片或日志。
